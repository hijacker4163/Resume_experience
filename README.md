# 專案經歷

## ML_Control 智能設備控制應用程式（美隆工業, 2024～）  

- **備註**: 獨立負責整體 iOS 應用開發，涵蓋專案規劃、UI/UX 設計、後台 API、資料庫串接等。  
- **平台支援**: iOS（Swift, MVVM 架構）  
- **功能亮點**:
  - **藍牙 / MQTT 裝置連線**：支援與公司智能設備進行 BLE 或 MQTT 通訊連線。
  - **遙控控制**：可透過 App 操作設備功能，包含播放、切換模式、自訂指令（Custom Command）等。
  - **EQ 圖形化調整介面**：提供直覺拖曳節點的方式，調整 EQ 頻率（Freq）、增益（Gain）、Q 值，並可同步設定傳輸至設備。
  - **雲端儲存與後台整合**：可將 EQ 設定儲存於雲端，並與公司內部後台串接進行帳戶與裝置資料同步。
  - **推播通知功能**：整合 FCM 實作設備通知推播。
